# مدرسة الأحد — نسخة Vercel

هذه نسخة مستقلة من واجهة تطبيق إدارة مدارس الأحد، جاهزة للرفع على Vercel.

## الرفع على Vercel

1. فك ضغط الملف.
2. في Vercel اختر **Add New Project** ثم **Import** أو ارفع مجلد المشروع.
3. اترك الإعدادات التلقائية، أو استخدم:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. اضغط **Deploy**.

## التشغيل محليًا

```bash
npm install
npm run dev
```

الحساب التجريبي داخل التطبيق:

- مالك الموقع: `owner` / `owner1234`
- أب الكنيسة: `father` / `1234`

> هذه النسخة تعمل كواجهة مستقلة، وتستخدم التخزين المحلي للبيانات والوسائط على نفس المتصفح. مشاركة الوسائط بين أجهزة متعددة تحتاج ربط Backend وقاعدة بيانات خارجية بعد النشر.
